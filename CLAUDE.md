# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Single `index.html` file — a U8g2 font preview tool. No build step, no dependencies, no bundler. Everything (HTML, CSS, JS) lives in `index.html`. Two Node maintenance scripts (`gen-heights.js`, `gen-glyph-index.js`) regenerate embedded/static metadata; they are not part of the runtime.

## Running Locally

```bash
python3 -m http.server 8080
# then open http://localhost:8080
```

A local server is required (not `file://`) because the app fetches external resources via `fetch()`.

## Architecture

### Data Flow

1. **Font index** — fetched once at startup from `https://raw.githubusercontent.com/wiki/olikraus/u8g2/fntlistallplain.md` (one font per line with its `fntgrp…` wiki link), parsed with a regex into ~2,000 font objects, cached in `sessionStorage`. `fntlistall.md` is kept as a fallback URL only; upstream turned it into a landing page with no font names.
2. **Heights** — `FONT_HEIGHTS` (between the `HEIGHTS_START`/`HEIGHTS_END` markers) maps every font name to its pixel height, pre-computed by `gen-heights.js` from the U8g2 font header. Fonts missing from the table show `?` until first render fills the height in.
3. **Glyph coverage** — `glyph-index.json` (generated by `gen-glyph-index.js`) lists the code-point ranges of every font. It drives the "search by chars" filter and the glyph browser. If it fails to load, the app indexes fonts in the background by downloading each `.c` file.
4. **Font data** — fetched on demand per selected font. The U8g2 binary `.c` file from `https://cdn.jsdelivr.net/gh/olikraus/u8g2@master/tools/font/build/single_font_files/<fullname>.c` is tried first (exact glyph set for that variant); the BDF source `tools/font/bdf/<base>.bdf` is the fallback. Parsed fonts are cached in memory, and concurrent requests for the same file share one in-flight fetch.
5. **Rendering** — pure-JS BDF parser and U8g2 `.c` decoder both produce the same `{glyphs, fontAscent, fontDescent}` shape, drawn onto `ImageData` and upscaled with nearest-neighbor (1×–4×). Each `renderPreview()` call takes a sequence number so a slow download cannot overwrite a newer preview.
6. **UI state** — preview text, W/H and scale persist in `localStorage`; the selected font lives in the URL hash (`#u8g2_font_ncenB08_tr`), so links are shareable. ↑/↓ keys step through the filtered font list.

### Font Name Parsing

U8g2 font names follow: `u8g2_font_<family><height>_<mode><charset>`

Example: `u8g2_font_ncenB08_tr` → family=`ncenB`, height=`08`, mode=`t` (transparent), charset=`r` (ASCII 32–127).

The BDF source filename is typically `<family><height>.bdf`, stored in `tools/font/bdf/` in the u8g2 repo. TTF-derived fonts (logisoso, PressStart2P, etc.) have no BDF source; they render from the `.c` file only.

### Key JS Sections (all inline in index.html)

| Section | Responsibility |
|---------|----------------|
| `loadFontList()` | Fetch + regex-parse wiki markdown into font objects (with `sessionStorage` cache) |
| `parseFont()` / `charsetKey()` | Split a font name into family/height/mode/charset and map charset to a filter bucket |
| `loadGlyphIndex()` / `startBackgroundIndexing()` | Load `glyph-index.json`, or build coverage in the browser if it is missing |
| `parseBDF()` | Parse raw BDF text → `Map<codepoint, glyph>` |
| `parseCFontBytes()` → `parseU8G2Font()` | Decode a U8g2 `.c` font (string literal → bytes → header → RLE glyphs) into the same shape |
| `fetchU8G2()` / `fetchBDF()` | Fetch + parse with memory cache and in-flight de-duplication |
| `renderText()` | Draw text onto `ImageData`, center + clip to canvas bounds |
| `showOnCanvas()` | Nearest-neighbor upscale of ImageData to display canvas |
| `renderPreview()` | Orchestrates fetch → render → status line; drops stale results |
| `applyFilters()` | AND-combine name search, char search, height, mode and charset tri-state filters |
| `renderGlyphBrowser()` | Group a font's code points by Unicode block into click-to-insert buttons |
| `setupEvents()` | Wire filters, font list clicks, keyboard navigation, hash links, text/W/H/scale controls |

### External URLs Used

- Font list (CORS-OK): `https://raw.githubusercontent.com/wiki/olikraus/u8g2/fntlistallplain.md`
- U8g2 `.c` fonts (CORS-OK via jsDelivr): `https://cdn.jsdelivr.net/gh/olikraus/u8g2@master/tools/font/build/single_font_files/<fullname>.c`
- BDF files (CORS-OK via jsDelivr): `https://cdn.jsdelivr.net/gh/olikraus/u8g2@master/tools/font/bdf/<name>.bdf`
- U8g2 wiki group page: `https://github.com/olikraus/u8g2/wiki/fntgrp<family>`
- Single `.c` font file: `https://github.com/olikraus/u8g2/blob/master/tools/font/build/single_font_files/<fullname>.c`
